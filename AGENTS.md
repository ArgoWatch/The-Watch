# The Watch

Unofficial Argonauts player. Not affiliated with ACK or Muse Facktory.

## Product
- Static site only. No backend, no wallet, no analytics, no prices.
- Mode row is **Play / Strip / Draw / Curate**. (Curate used to be labeled Crew.) Sheet sits under Draw in that same column. That is the row. Do not add a fifth mode. Do not turn the row into a wrapping grid of chips. Do not move Curate into the path line “because paths are not a fourth mode.”
- Art is loaded from Ethereum via tokenURI / render. Do not invent pixels.
- Copyright stays with ACK. Do not say we made the Argonauts.
- Do not use “score”, rarity, floor, or flip language in the UI.

## Stack
- Plain HTML, CSS, JS. No React, no bundler unless truly needed.
- Local first. Publishing is GitHub Pages from this static tree (no server), on the **ArgoWatch** hobby account — not a company GitHub. Free Pages needs a **public** repo; private Pages needs GitHub Pro.
- Integer pixel scaling only. image-rendering: pixelated.
- The plate is 4 physical inches square (the print). Do not use CSS `4in` — browsers treat that as 96dpi (384px), which is not a ruler inch on most panels. Pick the integer scale nearest 4in from the screen's pixel size and a typical diagonal; shrink only if the window cannot fit it.

## Contract
- 0x387C41B0B2F1128dE44dB1Bcf8baad085f26392C
- traitsOf(uint256) → uint8[7]
- Slots: 0 Palette, 1 Bones, 2 Cloak, 3 Relic, 4 Sight, 5 Artifact, 6 Crown
- tokenURI may revert for unminted ids
- traitsOf is meant to be frozen (TableFrozen). Renderer can change via setRenderer. Art is always live. The trait snapshot is not.
- After ACK touches the table (or burned/fate-style extras appear), re-run `node scripts/fetch-traits.mjs`. `node scripts/check-traits.mjs` samples live traitsOf against the snapshot. The player canaries the current id (and once per session `id+97` and `id+333`) against the snapshot; on mismatch it keeps playing from live `traitsOf` for that id and asks to re-run the fetch script. SVG cache is keyed by renderer+id+source (`uri` or `render`), 5 minute TTL. Renderer address change drops other keys. Strip always fetches tokenURI fresh. Unmounted ids: the plate well tints to the palette and reads UNMINTED; the body is already in that square at opacity 0, then word and body crossfade in place — no stamp-lamp, no Draw-as-print. Print wins when `tokenURI` exists. Do not add a nightly Action that re-fetches 9,999 tokenURIs.

## Taste
- Dark salon / parchment / hairline gold. Quiet. No rarity badges.
- The work is the picture. Transport chrome is text-only. Bottom Play/Prev/Next appears on hover of the plate (desktop) or tap (phone), then fades after **4s**. Using a control or the id box resets the timer; resting the mouse on that toolbar keeps it up; leaving the mouse on the plate does not.
- **Play paths are not modes.** The path line under Play is Fleet, Unclothed, Cloak, Relic, Sight, Artifact, Crown — a closed set, current path underlined. Desktop: hover Play / Strip / Draw shows it; it stays in that cluster, then fades 4s after leave. Phone: tap Play. Not tied to the bottom toolbar. Clicking a path starts Play from the first (lowest) id — no extra Play press. The Watch title returns to the first id of the current path. Do not add 2-trait, “has this trait,” listed, burned-only, or shop filters. No counts. No Fate path. Do not promote a path chip into the Play/Strip/Draw/Curate row.
- **Curate** (formerly **Crew**) is the fourth control on the mode row. Leave it there. Do not “fix” it into the path grid, a second row of modes, or a wrapping chip field. Clicking Curate from Strip or Draw leaves that mode first, then opens or restores Curate. Internal ids, `lib/crew.js`, and the `?crew=` query key stay `crew` so old links keep working.
- **Curate chrome** (address fields, path line, strip) stays up while a curated show plays. **Curate** or **−** (same type as Suit Up, tight pair with **×**) hides every Curate control; Curate again brings it all back, address bar included. **×** leaves Curate and remembers the last show in memory; Curate from Fleet restores it. Last address-row **×** forgets the show and returns to Fleet (keep playing if a show was on). Ossen’s wallet is the example. Phone: the address field is a form; Go/Enter submits — it does not tab to the id box. **+** adds another field (max 4).
- **Curate path order:** − ×, Suit Up (cloak-none then cloak, fewest worn first), Themes, As Minted (id order), As Received, As Arranged. Multi-word labels stay one chip. Themes is a rolodex that rests on the word Themes; ‹ › or tapping Themes plays the next echo. Echoes (cap ten, no “Your”): Bare Bones, then worn categories (Cloak, Relic, Sight, Artifact, Crown) when that slot is a theme — a single repeating relic is Relic, not its value name (Gold). Specific names only when two or more different values share the slot. Then Bones, then Palette. As Received is first inbound log per current holding across the curated wallets (earliest block wins; one timeline, not wallet-then-wallet). Omit the path if logs fail. Strip wells appear as each ownerOf returns; pictures fill as tokenURI arrives. × under a well leaves that Argo. Desktop: drag to arrange. Phone: tap one well then another to move; while a show is playing, tap a well to pause on that Argo. Curate flashes and grows an ellipsis while the chain is read.
- While a path is playing, a click on a twin or stem/apex door pauses the walk, runs that door, returns home, then resumes; a burnt Argo pauses for the clock until Play. While paused, the same doors run then return to the clicked Argo and wait (twins hold one film beat on the pair). Prev, Next, a new path, Strip, Draw, and Pause cancel the trip and do not auto-resume.
- Wordmark: The Watch. Click it to restart the current path from the first frame. **Play** toggles play / pause (and on a phone shows the path line). **Strip** toggles explode / reassemble. Play from Strip or Draw leaves that mode and resumes the slideshow in one press.
- Isolation well is 2in square on desktop (half the 4in plate). On narrow screens, isolation is half the assembled scale and sits to the right of the plate list. None plates are not clickable. Well color is locked per trait name (all Woodpipes share one well). Dark names (Death, Corsair, Eye Patch, pipe, etc.) use paper; otherwise only near-black luma (not dark gold).
- Touch: tap empty canvas to show transport chrome for 4s; interacting with a control resets the timer. Sheet sits under Draw (same column as Draw / Pause). Fate (and other non-slot extras except Print) are inert, like None. On a phone, pull down from above the plate (mast, padding, or a vertical drag that started on Play/Strip/Draw) reloads. The picture itself does not. Desktop does not pull-to-reload — mouse drag from the header must not slide the salon or eat Play/Strip/Draw clicks.
- Isolate occupancy on a **bare skeleton** (so covered smoke still belongs to the artifact). Bones occupancy is vs the **render** ground, not the print ground, so a burnt field does not swallow the skeleton. Each well shows that slot’s own contract fills on black or paper, not composited through the palette — smoke stays the pipe’s gray-blue at the contract `fill-opacity`, not MuseGreen shining through. Exception: where `tokenURI` rewrites a renderer pixel (Dragon's Breath tip is green in the print, blue in render; same Artifact id as Blueberry Kush) isolation follows the print. Skip ACK print stamps (1×1 black/white at fill-opacity ~0.11–0.14) so they do not show as solid dots on Bones or any plate. Fainter #000/#fff 1×1s (below ~0.10) are paint, not stamps — Golden Fleece wool leaks two of these; they stay off the Stamp plate. Show true stamps on their own **Stamp** plate (value `print overlay`, not a trait; muted well so both polarities read; true opacity). Burns with no stamps get Stamp None, inert. Palette = ground color on its own well. Bones and accessories on black (paper for named darks — Void, Death, pipes, Fleece — and near-black luma, so dark contract paint is not lost in the well). Print links to Harbor `/argonaut/{id}`. Draw still paints the Fleece blend in document order.

While plotting, the Draw label reads **Pause**; press it to pause, again to resume. **Reset** restarts the plot. **Play** in Draw mode leaves Draw and resumes the slideshow. **Sheet** sits under Draw (same column) and downloads a night-mode 24×24 graph-paper PDF (white field only; site colors elsewhere).

## Security
- No wallet, no cookies, no analytics, no third-party scripts, no inline JS.
- CSP in index.html: default-src none; connect-src is `'self'` plus the **RPC origins** (scheme + host, no path). `lib/chain.js` `RPC_URLS` is the full URL the fetch hits (path allowed). They must agree on host. `https://1rpc.io` in CSP covers JS `https://1rpc.io/eth`. If you add an RPC, add the origin to CSP **and** the exact URL to `RPC_URLS` or Curate/Play fail closed on that endpoint.
- Rebuild SVG from rect + hex fills. Drop scripts, urls, foreignObject, event handlers.
- Allowlisted RPC methods: `eth_call`, `eth_getLogs`, `eth_blockNumber`. Token ids 1–9999. Collection, DeadClock, and the current renderer only. Do not commit RPC keys.
- Failover: `RPC_URLS` in `lib/chain.js` (publicnode first, cloudflare last). `rpcIndex` sticks on success and walks the list on failure / timeout (5s). Keep that rotation. If one public node rate-limits Curate `getLogs`, the next URL should pick up.
- Curate holdings (`lib/crew.js`, formerly the Crew scan): Transfer logs from mint block `25837531` in 8000-block chunks, inbound from both ends, split the chunk on error, `ownerOf` to confirm, stop early when `balanceOf` is satisfied, skip a wallet whose IDB cache is fresh (~30 min). Art SVG cache remains 5 minutes. If Curate feels broken or crawls in the wild, this scan is the first place to look. Not 9,999 `ownerOf` and not ERC721Enumerable.
