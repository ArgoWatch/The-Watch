# The Watch

Unofficial Argonauts player. Not affiliated with ACK or Muse Facktory.

## Product
- Static site only. No backend, no wallet, no analytics, no prices.
- Mode row is **Play / Strip / Draw / Crew**. Sheet sits under Draw in that same column. That is the row. Do not add a fifth mode. Do not turn the row into a wrapping grid of chips. Do not move Crew into the path line “because paths are not a fourth mode.”
- Art is loaded from Ethereum via tokenURI / render. Do not invent pixels.
- Copyright stays with ACK. Do not say we made the Argonauts.
- Do not use “score”, rarity, floor, or flip language in the UI.

## Stack
- Plain HTML, CSS, JS. No React, no bundler unless truly needed.
- Local first. Publishing is GitHub Pages from this static tree (no server), on the **ArgoWatch** hobby account — not a company GitHub. Free Pages needs a **public** repo; private Pages needs GitHub Pro.
- Integer pixel scaling only. image-rendering: pixelated.
- The plate is a **4 inch × 4 inch square** (each **side** is 4 in). Do not use CSS `4in` (96dpi = 384px). CSS pixels per inch = `hypot(screenCssW, screenCssH) / assumedPanelInches`; each side is `4 ×` that. Brave Shields **farble** `screen.width` / `height` to the window, so a desktop tab looks like a tiny panel and the print shrinks — if `screen.width` tracks `innerWidth` and the window is under ~1700px CSS, use 140 CSS px per inch instead (about a 15.6" 1080p ruler inch). We cannot read another browser’s screen from GitHub Pages. Same math otherwise; no `getBattery`. Shrink only if the window cannot fit. On a phone the cap is the viewport.

## Contract
- 0x387C41B0B2F1128dE44dB1Bcf8baad085f26392C
- traitsOf(uint256) → uint8[7]
- Slots: 0 Palette, 1 Bones, 2 Cloak, 3 Relic, 4 Sight, 5 Artifact, 6 Crown
- tokenURI may revert for unminted ids
- traitsOf is meant to be frozen (TableFrozen). Renderer can change via setRenderer. Art is always live. The trait snapshot is not.
- After ACK touches the table (or burned/fate-style extras appear), re-run `node scripts/fetch-traits.mjs`. `node scripts/check-traits.mjs` samples live traitsOf against the snapshot. The player canaries the current id (and once per session `id+97` and `id+333`) against the snapshot; on mismatch it keeps playing from live `traitsOf` for that id and asks to re-run the fetch script. SVG cache is keyed by renderer+id+source (`uri` or `render`), 5 minute TTL. Renderer address change drops other keys. Strip always fetches tokenURI fresh. Unmounted ids: the plate well tints to the palette and reads UNMINTED; the body is already in that square at opacity 0, then word and body crossfade in place — no stamp-lamp, no Draw-as-print. Print wins when `tokenURI` exists. Do not add a nightly Action that re-fetches 9,999 tokenURIs.

## Taste
- Dark salon / parchment / hairline gold. Quiet. No rarity badges.
- The work is the picture. Transport chrome is text-only. Bottom Play/Prev/Next appears on hover of the plate (desktop) or tap (phone), then fades after **4s**. Using a control or the id box resets the timer; resting the mouse on that toolbar keeps it up; leaving the mouse on the plate does not.
- **Play paths are not modes.** The path line under Play is Fleet, Unclothed, Cloak, Relic, Sight, Artifact, Crown — a closed set, current path underlined. Desktop: hover Play / Strip / Draw shows it; it stays in that cluster, then fades 4s after leave. Phone: tap Play. Not tied to the bottom toolbar. Clicking a path starts Play from the first (lowest) id — no extra Play press. The Watch title returns to the first id of the current path. Do not add 2-trait, “has this trait,” listed, burned-only, or shop filters. No counts. No Fate path. Do not promote a path chip into the Play/Strip/Draw/Crew row.
- **Crew is the fourth control on the mode row.** Leave it there. Do not “fix” it into the path grid, a second row of modes, or a wrapping chip field. Clicking Crew from Strip or Draw leaves that mode first, then opens or restores Crew.
- **Crew chrome** (address fields, crew path line, strip) stays up while a crew show plays. **Crew** or **−** (same type as Suit Up, tight pair with **×**) hides every crew control; Crew again brings it all back, address bar included. **×** leaves Crew and remembers the last show in memory; Crew from Fleet restores it. Last address-row **×** forgets the crew and returns to Fleet (keep playing if a show was on). Leaving Crew (either **×**) restores Fleet / Unclothed / Cloak / … and starts the same 4s path fade as a Play tap — do not leave `paths-on` stuck from Crew (phone has no hover, so they would stay up). Ossen’s wallet is the example. Phone: the address field is a form; Go/Enter submits — it does not tab to the id box. **+** adds another field (max 4) and **keeps** the strip while the new wallet streams in. Pasting over an existing address (or otherwise dropping a wallet from the list) **clears that wallet’s Argos first**, then fills the new set — do not union the old strip onto a replacement address.
- **Crew path order:** − ×, Suit Up (cloak-none then cloak, fewest worn first), Themes, As Minted (id order), As Received, As Arranged. Multi-word labels stay one chip. Themes is a rolodex that rests on the word Themes; ‹ › or tapping Themes plays the next echo. As Received is first inbound log per current holding across the crew wallets (earliest block wins; one timeline, not wallet-then-wallet). Omit the path if logs fail. Strip wells appear as each ownerOf returns; pictures fill as tokenURI arrives. × under a well leaves that Argo. Desktop: drag to arrange. Phone: tap one well then another to move; while a show is playing, tap a well to pause on that Argo. Crew flashes and grows an ellipsis while the chain is read.

## Security
- No wallet, no cookies, no analytics, no third-party scripts, no inline JS.
- CSP in index.html: default-src none; connect-src is `'self'` plus the **RPC origins** (scheme + host, no path). `lib/chain.js` `RPC_URLS` is the full URL the fetch hits (path allowed). They must agree on host. `https://1rpc.io` in CSP covers JS `https://1rpc.io/eth`. If you add an RPC, add the origin to CSP **and** the exact URL to `RPC_URLS` or Crew/Play fail closed on that endpoint.
- Rebuild SVG from rect + hex fills. Drop scripts, urls, foreignObject, event handlers.
- Allowlisted RPC methods: `eth_call`, `eth_getLogs`, `eth_blockNumber`. Token ids 1–9999. Collection, DeadClock, and the current renderer only. Do not commit RPC keys.
- Failover: `RPC_URLS` in `lib/chain.js` (publicnode first, cloudflare last) for `eth_call` / `eth_blockNumber`. Crew `getLogs` uses `LOG_RPC_URLS` with its own cursor — not 1rpc or cloudflare (those cap log windows at 50 / 800 blocks and look empty). Pictures (`eth_call`) and the log scan must not share one sticky URL or desktop Firefox/Brave starve `tokenURI` and finish short of `balanceOf`. Walk the list on failure / timeout (5s call, 8s logs).
- Crew holdings: last night’s fast path — Transfer logs from mint block `25837531` in 8000-block chunks, inbound from both ends, `ownerOf` to confirm, **stop when `balanceOf` is met**, skip a wallet whose IDB cache is fresh (~30 min). Do not split empty windows or walk the history twice for As Received on that first pass. `getLogs` uses `LOG_RPC_URLS` (not 1rpc/cloudflare) so pictures are not stuck on the same node. Shared URLs still carry `hold=` / `recv=`. If Crew crawls, this scan is the first place to look. Not 9,999 `ownerOf` and not ERC721Enumerable.
